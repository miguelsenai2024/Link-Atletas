# Participação individual

O PDF registra o acompanhamento de 20/10/2026. O TSV exporta o histórico real de commits alcançáveis pela `main` atual; nomes são as identidades gravadas no Git.

Esses materiais são apoio histórico. Ainda é necessário consolidar as contribuições finais de cada integrante com evidências próprias, datas e descrição. Autoria Git não comprova automaticamente a participação de toda a equipe. Nenhuma atribuição individual foi inventada.
